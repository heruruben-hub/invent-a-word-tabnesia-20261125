An entry for the [Invent a Word We Need](https://make.fun/c/u-deranalabs-invent-a-word-we-need-17a020e0) bounty on make.fun.

## The word

> **Tabnesia (n.): forgetting why you opened a tab the moment it loads.**

## How it works

`main.py` writes the one-line entry above to `/output/entry.txt`. That is the whole entry: one invented English word and its definition in a single clear line (67 characters).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
